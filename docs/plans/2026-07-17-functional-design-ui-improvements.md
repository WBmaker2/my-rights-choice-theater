# 내 권리 선택 극장 기능·디자인·UI 개선 계획

**작성일:** 2026-07-17  
**대상:** 초등 1~2학년 학생용 공개 웹앱  
**점검 환경:** 공개 배포본, 데스크톱 1280×720 및 모바일 375×812

## 1. 점검 결과

첫 화면은 따뜻한 색상, 큰 제목, 명확한 시작 버튼, 개인정보 비수집 안내가 잘 갖춰져 있습니다. 실제 학생 흐름을 모바일에서 끝까지 따라가며 다음 개선 필요를 확인했습니다.

| 우선순위 | 발견한 문제 | 학생에게 미치는 영향 | 개선 방향 |
|---|---|---|---|
| 높음 | 모바일 헤더에서 `활동 끝내기`가 숨겨짐 | 민감한 장면을 보고 있을 때 활동 자체를 종료할 방법이 보이지 않음 | 활동 중에는 모든 화면 크기에서 종료 버튼을 표시하고, 실수로 누르면 확인창을 거치게 함 |
| 높음 | 권리 선택 화면에 전체 권리 카드 5개가 모두 노출됨 | 한 장면에서 긴 목록을 읽어야 하며 핵심 선택까지 스크롤이 길어짐 | 장면과 연결되는 권리 카드 3개만 보여 주고, 정오 판정 없이 복수 선택을 유지함 |
| 높음 | 진행 표시가 `1 / 5 장면`만 알려 줌 | 현재 장면 안에서 어디까지 왔는지 알기 어려움 | `장면 보기`, `지켜져야 할 것`, `도움 문장` 등 8단계 이름과 진행 막대를 함께 표시함 |
| 중간 | `이 장면 건너뛰기`가 긴 본문 뒤에 있음 | 보고 싶지 않은 내용을 넘기려면 화면 끝까지 내려가야 함 | 장면 활동 본문을 읽기 전에 바로 보이는 상단 건너뛰기 도구로 이동함 |
| 중간 | 어른 응답 이후 화면은 뒤로 돌아가기 어려움 | 도움 문장이나 어른 응답을 다시 확인·수정하기 어려움 | 주요 후반 화면에 명확한 이전 버튼을 추가함 |
| 중간 | 화면 전환 뒤 키보드·보조기기 초점이 이전 버튼에 남음 | 새 화면의 제목을 놓치거나 현재 위치를 파악하기 어려움 | 화면 전환 시 새 제목으로 초점을 옮기고 화면 상단으로 스크롤함 |
| 낮음 | 모바일 제목과 버튼의 눌림 피드백이 다소 약함 | 조작 결과를 즉시 느끼기 어려움 | 제목 줄바꿈 균형과 버튼 활성 상태를 보강함 |

## 2. 구현 범위

1. 장면별 `rightOptions` 3개를 콘텐츠 데이터에 명시하고 계약 검증을 추가합니다.
2. 헤더에 장면 진행과 장면 안 단계 진행을 함께 표시합니다.
3. 활동 중에만 `활동 끝내기`를 노출하며, 종료 확인 모달을 추가합니다.
4. 장면 건너뛰기 도구를 콘텐츠를 가리지 않는 본문 앞 안전 도구로 이동합니다.
5. 어른 응답·다른 어른·장면 정리 화면에 이전 이동을 추가합니다.
6. 화면 전환 시 제목 초점 및 상단 이동을 적용합니다.
7. 업데이트 내역에 2026-07-17 개선 내용을 추가합니다.

## 3. 테스트와 완료 기준

- 모바일 375×812에서 활동 중 `활동 끝내기`와 `이 장면 건너뛰기`가 보입니다.
- 종료 버튼을 눌러도 확인 전에는 진행 내용이 사라지지 않습니다.
- 첫 장면 권리 선택 화면에는 장면별 카드 3개만 보입니다.
- 헤더가 `현재 장면 / 전체 장면`, `현재 단계 / 전체 단계`, 단계 이름을 전달합니다.
- 후반 화면에서 앞 단계로 돌아가 도움 문장과 응답을 다시 확인할 수 있습니다.
- 화면 전환 뒤 새 화면 제목에 초점이 갑니다.
- 기존 콘텐츠 계약, 도움 문장, 전체 학생 흐름 테스트가 모두 통과합니다.
- 프로덕션 빌드와 실제 브라우저 모바일 재점검을 통과합니다.
