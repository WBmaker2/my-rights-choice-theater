# 5단계 완료 축하 모달 계획

## 목표

5개 장면을 모두 살펴본 뒤 어린이가 활동을 끝냈다는 사실을 알아차리고, 다음 선택을 쉽게 고를 수 있는 반응형 축하 오버레이를 제공합니다.

## 현재 흐름

- 마지막 장면의 `이 장면 정리하기` 다음에 `summary` 화면이 표시됩니다.
- 마지막 summary의 `나의 도움 문장 모음` 버튼을 누르면 `session` 화면으로 이동합니다.
- `session` 화면에는 처음부터 다시 보기만 있어 종료 선택이 화면 안에서 분명하지 않습니다.

## 구현 범위

- `session` 화면에 축하 오버레이 모달을 표시합니다.
- 모달에 `종료`와 `처음부터 다시` 버튼을 배치합니다.
- `처음부터 다시`는 기존 초기화 로직을 사용해 첫 화면으로 돌아갑니다.
- `종료`는 기존 활동 종료 상태로 이동해 사용자가 활동을 여기서 마칠 수 있게 합니다.
- 기존 `Modal` 컴포넌트와 반응형 모달 스타일을 재사용하고, 중요한 선택 버튼에는 기존 `gi-pulse` 효과를 유지합니다.
- 업데이트 내역에 변경 사항을 기록합니다.

## 검증

- 마지막 장면에서 완료 모달이 나타나는지 확인합니다.
- `처음부터 다시`와 `종료`의 상태 전환을 테스트합니다.
- 모바일 폭에서 모달이 화면 안에 들어오고 버튼이 세로로 배치되는지 확인합니다.
- 린트·단위 테스트·빌드·정적 Pages 빌드를 실행합니다.
