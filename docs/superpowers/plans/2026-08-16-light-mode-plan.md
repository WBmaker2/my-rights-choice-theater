# 라이트 모드 고정 계획

## 목표

ChatGPT 내장 브라우저의 다크 색상 선호와 관계없이 초등학생용 앱을 읽기 쉬운 라이트 모드로 고정합니다.

## 확인된 현황

- 내장 브라우저에서 `prefers-color-scheme: dark`가 `true`였습니다.
- 기존 토큰과 일부 버튼 스타일이 다크 모드 미디어 쿼리로 어두운 색을 적용하고 있었습니다.

## 구현 범위

- `color-scheme: light`를 기본 토큰에 선언합니다.
- 다크 모드 색상 토큰과 다크 전용 컴포넌트 스타일을 제거합니다.
- 업데이트 내역에 라이트 모드 고정 변경을 기록합니다.

## 검증 계획

- 린트, 단위 테스트, 서버 빌드, GitHub Pages 정적 빌드를 실행합니다.
- 공개 배포 후 내장 브라우저에서 `colorScheme`, 배경색, 다크 미디어 규칙을 확인합니다.
