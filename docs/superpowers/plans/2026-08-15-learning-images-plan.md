# 학습용 이미지 생성·삽입 계획

## 목표

초등학교 1~2학년 사용자가 이야기 장면을 글만 읽지 않고 한눈에 이해할 수 있도록, 앱의 5개 학습 장면을 이미지 생성 모델로 만든 일관된 일러스트로 교체한다.

## 현황 분석

- `public/og.png`는 공유·미리보기용 소개 카드이며 학습 장면에 직접 쓰이지 않는다.
- `app/content/scenes.ts`의 10개 패널은 이모지(`🧑‍🤝‍🧑`, `🎒`, `📷` 등)만 보여 준다.
- 권리·도움 방법·전달 방식 카드의 이모지는 작은 의미 표지로 사용되므로, 핵심 장면 이미지와 역할이 다르다.
- 장면별 `altText`가 이미 있어 이미지 접근성 문구로 재사용할 수 있다.

## 생성할 이미지

장면별 5개(각 장면의 두 패널에서 같은 맥락 이미지 사용)

1. `classroom-turn.webp` — 모둠 활동에서 말할 차례를 기다리는 어린이
2. `nickname-boundary.webp` — 원하지 않는 별명을 멈춰 달라고 말하는 어린이
3. `photo-consent.webp` — 사진을 올리기 전 먼저 물어보는 어린이
4. `online-privacy.webp` — 온라인 채팅에서 개인정보를 보내지 않고 어른에게 보여 주는 어린이
5. `safe-play.webp` — 거친 놀이에서 나와 안전한 곳으로 이동하는 어린이

공통 생성 기준: 따뜻한 평면 동화 일러스트, 초등 저학년 눈높이, 다양한 어린이, 글자·로고·실제 개인정보·위협적인 표정·폭력 표현 없음. 장면은 모두 가상 이야기이며 안전하게 도움을 요청하는 선택을 암시한다.

## 구현 범위

- 생성 결과를 `public/learning/`에 저장한다.
- 장면 데이터에 `imageSrc`를 추가하고 `SceneStage`에서 이미지와 접근성 대체 문구를 함께 렌더링한다.
- 기존 이모지 아이콘은 권리·도움 방법 카드의 빠른 의미 표지로 유지한다.
- 모바일에서도 이미지가 잘리지 않도록 원본 비율을 유지하는 반응형 `height: auto`와 `object-fit: contain`을 적용한다.
- 중요한 다음 단계 버튼에 `gi-pulse` 강조 효과를 적용한다.
- 업데이트 내역에 이미지 생성·삽입 내용을 `0.4.0`으로 기록한다.

## 검증

- 이미지 파일 5개가 모두 저장되고 장면별로 연결되었는지 확인한다.
- 린트·테스트·빌드를 실행한다.
- 375px 모바일에서 이미지가 가로로 넘치지 않고 장면 이동 버튼이 보이는지 브라우저로 확인한다.
- 생성 이미지가 텍스트를 포함하지 않고, 어린이에게 불필요하게 무서운 장면을 만들지 않았는지 시각적으로 확인한다.
