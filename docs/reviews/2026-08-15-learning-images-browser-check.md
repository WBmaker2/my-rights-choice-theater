# 학습 이미지 브라우저 표시 점검

## 점검 목적

생성한 학습용 이미지가 브라우저에서 전체 장면으로 보이는지, 이미지 파일 5개가 모두 앱에서 접근 가능한지 확인했습니다.

## 발견한 문제

`SceneStage`의 이미지에 원본 크기(`width="1448" height="1086"`)를 지정한 뒤 CSS에서 높이를 덮어쓰지 않아, 브라우저가 세로로 긴 이미지 박스를 만들고 기존 `object-fit: cover` 동작 때문에 좌우가 잘릴 수 있었습니다.

## 적용한 수정

- `.scene-art`에 `height: auto`를 적용해 원본 4:3 비율을 유지했습니다.
- `object-fit: contain`으로 이미지 전체가 프레임 안에 들어오도록 했습니다.
- 장면 프레임의 열 너비를 반응형 `minmax()`로 바꿔 데스크톱에서 그림과 설명이 균형 있게 보이도록 했습니다.
- 모바일에서는 이미지가 화면 너비 안에서 줄어들고, 전체 페이지 스크롤로 설명과 다음 버튼까지 이어서 볼 수 있도록 확인했습니다.

## 브라우저 확인 결과

Playwright 로컬 브라우저에서 다음을 확인했습니다.

| 확인 항목 | 결과 |
| --- | --- |
| 데스크톱 장면 스크린샷 | 전체 교실 장면과 네 명의 인물이 잘리지 않고 표시됨 |
| 모바일 장면 스크린샷 | 4:3 비율을 유지하며 전체 그림 표시 |
| 모바일 전체 페이지 | 그림·대사·다음 그림 버튼까지 세로 흐름 정상 |
| 이미지 로드 상태 | 5개 WebP 파일 모두 HTTP 200 |
| 실제 표시 비율 | `natural 1448×1086`, 모바일 렌더링 `267×200`, 비율 `1.333` |

스크린샷은 `output/playwright/scene-desktop-fixed.png`, `output/playwright/scene-mobile-fixed.png`, `output/playwright/scene-mobile-fixed-full.png`에 저장했습니다.
