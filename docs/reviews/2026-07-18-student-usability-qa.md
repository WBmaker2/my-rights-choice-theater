# 초등학생 관점 실사용 개선 및 재검증 기록

**점검일:** 2026-07-18

**대상:** 초등학교 1~2학년 학생

**대상 버전:** v0.3.0

## 점검 방법

- 로컬 프로덕션 빌드에서 첫 화면부터 첫 장면 정리까지 실제 버튼을 순서대로 눌렀습니다.
- 모바일 375×812, 태블릿 768×1024, 데스크톱 1280×720 화면을 비교했습니다.
- 문장 이해 난이도, 다음 행동의 예측 가능성, 카드 수, 건너뛰기 범위, 터치 영역, 가로 넘침과 브라우저 오류를 확인했습니다.
- 자동화 회귀 테스트로 같은 요구가 다시 깨지지 않도록 고정했습니다.

## 발견점과 구현 결과

| 발견점 | 학생에게 생기는 어려움 | 구현 결과 |
|---|---|---|
| `가상 인물`, `도움받을 자격`, `책임 있는 어른의 응답` 같은 추상적인 말 | 읽을 수 있어도 뜻을 바로 잡기 어려움 | `만든 이야기 속 친구`, `어떤 방법을 써도 도움받을 수 있어요`, `어른은 이렇게 도와야 해요`로 변경 |
| 모바일 시작·안내 헤더의 빈 둘째 줄 | 첫 행동이 아래로 밀리고 진행 표시가 버튼처럼 보임 | 실제 활동 전에는 진행 표시 전체를 숨기고 헤더를 한 줄로 정리 |
| 도움 방법 카드 5개 | 긴 스크롤과 비슷한 카드 사이에서 망설임 | 전용 단계에서 다시 다루는 `다른 어른` 카드를 제외해 4개로 정리 |
| 장면 완료 뒤에도 건너뛰기 표시 | 이미 마친 장면을 왜 건너뛰는지 혼란 | 장면·권리·도움 방법·도움 문장·알리기 화면에서만 표시 |
| `이전`, `어른 응답 다시 보기` | 누르면 어디로 가는지 예상하기 어려움 | `권리 카드 다시 보기`, `도움 방법 다시 보기`, `어른이 돕는 방법 다시 보기`로 변경 |
| `자리에서 벗어나기`, `도움을 요청할 수 있어요` | 저학년에게 딱딱하고 긴 표현 | `자리에서 나오기`, `어른에게 도와 달라고 하기`로 변경 |
| 모바일 브랜드 링크 40px 너비 | 권장 터치 너비보다 4px 작음 | 44×48px로 확대 |

## 안전 원칙 확인

- 실제 경험·이름·사진·목소리·위치를 묻거나 저장하지 않습니다.
- 말하기·카드 보여 주기·문장 가리키기를 같은 도움 방법으로 유지했습니다.
- 이유를 말하지 않는 장면 건너뛰기와 활동 끝내기를 유지했습니다.
- 다른 어른에게 다시 알리는 전용 단계와 모든 장면의 안내 문장을 유지했습니다.
- 긴급 도움 안내와 `112` 정보를 변경하지 않았습니다.
- 점수·정답·평가 요소를 추가하지 않았습니다.

## 자동 검증 결과

- Vitest 테스트 파일: 4개 통과
- 테스트 항목: 15개 통과
- 서버 렌더링 테스트: 1개 통과
- ESLint: 오류 0개
- 프로덕션 빌드: 성공
- 변경한 코드 파일: 모두 500줄 미만

## 실제 브라우저 재검증 결과

- 첫 화면 모바일 헤더 높이: 약 78px
- 활동 전 진행 표시: 없음
- 모바일 브랜드 터치 영역: 44×48px
- 도움 방법 카드: 4개
- 44px 미만 버튼·링크: 0개
- 모바일 가로 너비: `scrollWidth 375px`, `clientWidth 375px`
- 어른 도움·다른 어른·장면 정리 화면의 건너뛰기: 없음
- 브라우저 콘솔 오류: 없음

개선 전·후 스크린샷은 로컬 `.gstack/design-reports/screenshots/`에 보관했습니다.

## 최종 판단

초등학교 1~2학년 학생이 화면의 뜻과 다음 행동을 더 빠르게 이해할 수 있도록 핵심 문장과 조작 흐름이 개선됐습니다. 앱의 비수집 원칙과 여러 도움 경로는 그대로 유지됐으며 공개 배포 전 검증 기준을 충족했습니다.
