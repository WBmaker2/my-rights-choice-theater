# 장면 보호 검토 체크리스트

이 문서는 수업 공개 전 전문 검토를 기록하기 위한 양식입니다. 현재 앱의 장면은 모두 `review-ready`이며 전문 승인 완료 상태가 아닙니다.

## 검토 역할

- [ ] 초등 1~2학년 담임교사: 문장 길이, 어휘, 수업 흐름, 오해 가능성
- [ ] 학교 상담·아동보호 실무자: 학생 책임 전가, 위험한 조언, 도움 연결 문구
- [ ] 아동권리교육 전문가: 권리 조건화·서열화·과도한 단순화
- [ ] 특수·통합교육 또는 접근성 검토자: 말하기 편향, 읽기·운동·감각 접근성

## 장면별 확인

각 장면 ID에 대해 아래 항목을 확인하고 수정 후 다시 검토합니다.

- [ ] 사실만 짧게 보여 주며 학생의 마음을 단정하지 않는다.
- [ ] 직접 말하기 외에 이동, 카드, 어른 요청 경로가 있다.
- [ ] 말하지 않았거나 늦게 알린 일을 학생 잘못으로 표현하지 않는다.
- [ ] 비밀을 약속하거나 상대와 대면·증거 수집을 권하지 않는다.
- [ ] 어른 응답에 감사, 비난 배제, 즉시 보호, 후속 책임이 있다.
- [ ] 한 어른이 돕지 못할 때 다른 어른에게 다시 요청할 수 있다.
- [ ] 장면 건너뛰기가 즉시 가능하고 불이익이 없다.
- [ ] 실제 경험이나 개인정보를 묻지 않는다.
- [ ] 심각한 폭력·학대·성적 상황·자해 등 민감도 3 장면이 없다.
